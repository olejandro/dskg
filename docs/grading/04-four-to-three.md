# Fourth to Third Kyu

## Kihon: Basics

- From zenkutsu-dachi (front stance), gedan-barai (downward block)
	1. Chudan oizuki (middle level front punch) → 5X
	2. Chudan gyakuzuki (middle level reverse punch) → 5X
	3. Age-uke (rising block) ← 5X
	4. Soto-uke (outer block) → 5X
	5. Uchi-uke (inner block) ← 5X
- From kokutsu-dachi (back stance)
	- Shuto-uke (knife hand block) ← 5X
- From zenkutsu-dachi (front stance)
	1. Maegeri (front kick) → 5X
	2. Mawashigeri (roundhouse kick) → 5X
	3. Ushirogeri (back kick) → 5X
- From kiba-dachi (horse-riding stance)
	1. Yokogeri-keage (side snap kick) → 5X
	2. Yokogeri-kekomi (side thrust kick) → 5X

## Kata: Forms

- Tekki Shodan

## Kumite: Sparring

- Kihon ippon-kumite (basic one-step sparring)
	1. Jodan (head level)
	2. Chudan (middle level)
	3. Maegeri (front kick)
	4. Yokogeri (side kick)
	5. Mawashigeri (roundhouse kick)

# Note
First, examinees will be expected to perform all techniques from both sides.
Then, Examiner will choose one of each attack, and examinee will be expected to perform each technique on left and/or right side(s).
